01 / Overview

One task, clear boundaries

The skill checks user-provided text for spelling mistakes. Its default action is to return the complete text with likely spelling errors corrected, using British English spelling.

It keeps the original meaning, tone, and sentence structure. It does not rewrite sentences, adjust grammar or punctuation, or add facts unless the user asks for broader editing.

02 / Commands

Choose the kind of check

A supported command at the beginning of a request changes how the skill responds. With no command, it uses /correct and British English by default.

/check

Flag possible errors

Lists likely spelling mistakes and suggested corrections without rewriting the original text.

/correct

Return corrected text

Provides the complete text with spelling mistakes corrected. This is the default.

/explain

Explain changes

Adds a brief explanation of the spelling corrections.

/british

British spelling

Uses British English spelling conventions.

/american

American spelling

Uses American English spelling conventions.

/reset

Reset options

Clears options for the current request and returns to the defaults.

03 / Workflow

How a request is handled

The skill identifies the requested action and spelling variety, checks likely errors, and returns the result in the format appropriate to the command.

01

Read command

Find a supported command at the start of the message.

02

Set variety

Use British by default, or apply the requested variety.

03

Check words

Identify likely spelling mistakes in context.

04

Protect meaning

Review uncertain names and specialist terms before changing them.

05

Return result

Use the requested format and preserve the writer’s style.

04 / Example

Minimal, faithful correction

For a likely spelling mistake, the default correction returns the full sentence with the spelling fixed while leaving its grammar and phrasing intact.

Keep the writer’s voice

When a word may be a name, abbreviation, technical term, or intentional spelling, the skill flags uncertainty instead of silently changing it.

Illustrative example
Original: “She recieved the letter.”
Corrected: “She received the letter.”
05 / Limits

What it leaves to the writer

Names and specialist terms

Spellings of names, abbreviations, dialect, and technical vocabulary may be intentional. Uncertain cases are surfaced for review.

Not a general rewrite

Grammar, punctuation, wording, and style stay as written unless the user asks for those edits.

Conflicting varieties

British and American options cannot be used together. If both are requested, the skill asks which variety to follow.

Meaning stays with the author

The skill does not add facts or change the writer’s intended meaning.

Project principle

Correct the spelling. Keep the voice.

The skill’s central promise is a narrow, respectful edit: make likely spelling corrections while leaving the writer’s choices and intent intact.
